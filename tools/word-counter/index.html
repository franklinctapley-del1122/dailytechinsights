How it works

Words are counted as groups of non-whitespace characters. Character count includes spaces and punctuation. Sentence count is an estimate based on common sentence-ending punctuation, so abbreviations may affect the result.

When to use a word counter

Check blog post length, draft social updates, prepare descriptions, or keep writing within a word limit. Text is processed in this browser and is not sent to a server by this tool.
