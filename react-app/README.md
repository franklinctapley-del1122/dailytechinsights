# DailyTechInsights React production site

This Next.js + React static export is the production build for DailyTechInsights. The homepage uses the redesigned React experience; all existing HTML routes are rendered from preserved source snapshots with page titles, descriptions, canonical URLs, robots directives, inline styles, structured data, shared navigation/footer, and trailing-slash URLs preserved.

Run `npm run build` at the repository root. Vercel publishes `react-app/out`.
